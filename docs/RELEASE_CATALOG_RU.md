# Единый каталог выпусков TrussLab Architect

**Правило оформления:** `TrussLab Architect X.0 — Название подсистемы`. Релизный архив содержит `TrussLab_Architect_X_0.html`, `TrussLab_Architect_X_0_Portable.zip`, `TrussLab_Architect_X_0_Source.zip`. В `main` остаются только исходники, скрипты, тесты, документы; бинарные артефакты — в Releases. Старые теги и уже скачанные архивы **не переписываются задним числом**.

| Фактический опубликованный тег | Название релиза | Какая серия исходного roadmap вошла | Состояние |
|---|---|---|---|
| `v13.0.0` | **RenderCore 2** | 12.1–12.9, а также накопленные корректировки 11.x | Опубликован; некоторые визуальные функции имеют ограничения |
| `v14.0.0` | **WorldEditor 2** | 13.1–13.9 | Опубликован; игровая реконструкция, не точная 1:1 |
| `v15.0.0` | **InfrastructureSim** | 14.1–14.9 | Опубликован; учебная инфраструктурная симуляция |
| — | **CitySim / WorldStream** | 15.1–15.10 | Только автономные промежуточные HTML, **не** входит в архив v15.0.0 |
| — | **NatureWorld** | 16.1–16.9 | Отдельный этап разработки; статус определяется тестами, не номером версии |
| v17.x.0 | PlanetStream | 17.1–17.9 | Учебный регион, импорт и потоковая загрузка |

Для серий 17–20 доступны TrussLab_X.Y_SAFE.html, TrussLab_X.Y_LAB.html, Portable.zip и Source.zip. Фактический перечень файлов каждого тега опубликован в [GitHub Releases](https://github.com/OldFikus/TrussLab-Architect/releases).

## Порядок публикации

1. Сохранять полный текст [исходной дорожной карты](../ROADMAP_10_8_TO_20_0_RU.md), даже при изменении нумерации фактических архивов.
2. В описании каждого опубликованного тега указывать **две независимые сущности:** «номер публикации» и «подпункты исходного плана». Это предотвращает путаницу вида «релиз 15.0 = CitySim».
3. Исторические `v13.0.0`, `v14.0.0`, `v15.0.0` и их assets не переименовывать задним числом, чтобы старые ссылки, checksum и сохранения оставались проверяемыми.
4. При следующем крупном выпуске отдельно перечислять новые возможности, незавершённые функции и ограничения аппаратных тестов.

**16.0 NatureWorld по первоначальному плану:** 16.1 почвы/породы; 16.2 деревья/трава; 16.3 погодные фронты, осадки, облака; 16.4 волны и прибой; 16.5 дни, ночи, сезоны; 16.6 моря/реки; 16.7 сезонные материалы; 16.8 влияние на транспорт/видимость; 16.9 экологический performance budget и стресс-тесты.
