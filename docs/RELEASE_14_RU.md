# TrussLab Architect 14.0 — WorldEditor 2

Релиз продолжает 13.0 RenderCore Completion и добавляет WorldEditor 2 (версия разработки 13.9) в основную HTML-сборку.

## Новые инструменты

- 13.1 — участки и зоны в системе WGS84 / ECEF / ENU;
- 13.2 — каталог процедурных домов и инфраструктуры с авторством и лицензией;
- 13.3 — линии улиц, тротуаров, развязок, железнодорожных путей и условных стрелок;
- 13.4 — инженерные сети с проверкой связности;
- 13.5 — редактор рельефа, который хранит правки отдельно от DEM;
- 13.6 — процедурные фасады, модульные здания, несколько этажей;
- 13.7 — наследование и варианты материалов;
- 13.8 — история изменений, undo/redo, снимки и JSON-проекты;
- 13.9 — импорт GIS-полигонов с ручной проверкой предложений.

Региональная 3D-сцена получает пользовательские объекты в ENU-метрах. Встроенный GeoPack остаётся без изменений; географические оси моста пока приблизительные. Игровая железнодорожная стрелка — схема, без настоящей диспетчеризации; инженерные сети не рассчитывают давление или безопасность сооружений.

## Тесты

В локальной тестовой среде проходят `test_worldeditor_core.cjs`, `test_wgs84_alignment.cjs`, `test_worldeditor_browser.py` и `test_worldeditor_advanced.py`. GitHub Actions автоматически выполняет тесты Node.js, проверку синтаксиса, сборку и публикует автономные файлы в Releases. WebGPU и FPS на ПК пользователя требуют отдельной аппаратной проверки.
