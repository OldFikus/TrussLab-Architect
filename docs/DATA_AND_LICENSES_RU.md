# Источники данных и ограничения прав

- **Карта рельефа:** Copernicus DEM GLO-30, модель поверхности (DSM). Авторство Copernicus Programme / ESA. Не является батиметрией или инженерной съёмкой.
- **Берега:** OSM-производный `@geo-maps/earth-seas-10m` (исторический срез примерно 2017 года). Авторство © OpenStreetMap contributors; лицензия ODbL 1.0. Не текущий непрерывный поток OSM.
- **Городские GIS-данные:** пользователь может импортировать GeoJSON Overture Maps или OpenStreetMap. Конкретные источники и права зависят от каждого импорта; синтетические демонстрационные города не являются существующей застройкой.
- **Модели GLB в assets/models:** оригинальные демонстрационные ассеты TrussLab, а не реконструкции настоящих сооружений.
- **Спутниковый снимок пользователя:** намеренно не включён в публичные GitHub-файлы; нельзя автоматически публиковать скриншоты Google Maps/Street View как игровые текстуры без отдельного разрешения.
- **Метрический базис 11.0:** WGS84 → ECEF → ENU; это математическая привязка, не гарантия качества исходной геометрии. Старый мост расположен по приближённому визуальному ориентиру.

Сведения о наборе, метаданные и копирайты сохраняйте при каждом новом импорте. Для нового региона нужно отдельно проверить геодезическую точность и права на исходники.
