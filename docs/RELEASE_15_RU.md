# TrussLab Architect 15.0 — InfrastructureSim

Большой релиз InfrastructureSim на базе WorldEditor 2, автономный HTML.

## Реализовано

- Маршрутизация дорожной сети на основе пользовательских линий; двухпутные ж/д пути и сигналы в демонстрационной системе.
- Ограниченный поток агентов автомобилей, диспетчер поездов, суда, условные габариты.
- Учебные расчёты прогибов, реакций опор и фундаментов, сценарии погоды и снимки.
- Импорт/экспорт WorldEditor и InfrastructureSim, интеграция редакторов и 3D-региона.

## Ограничения

Сеть InfrastructureSim визуализируется на отдельном 2D-плане. Единого полностью редактируемого 3D-региона с CitySim здесь пока нет — это задача следующего этапа. Реальные геодезические оси и инженерная безопасность не подтверждены.

## Сборка и тесты

`python tools/build.py` и `node tests/test_infrastructure.cjs`, `node tests/test_infrastructure_stress.cjs`, `node tests/test_worldeditor_core.cjs`.

GitHub Release содержит готовый HTML, portable ZIP и исходный ZIP. В основной ветке хранятся только исходники, документация и тесты.
