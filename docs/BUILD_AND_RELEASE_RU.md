# Сборка и GitHub Releases

## Локальная сборка

`python tools/build.py`

Требуется Python 3.10+. Для HTML не нужны сервер, npm, API-ключи или загрузка карт извне. При желании проверить синтаксис JavaScript: `node --check src/game.js`.

## Структура

- `src/game.js` — основное автономное приложение со встроенными демонстрационными данными;
- `src/rendercore/` — небольшие модули графических вычислений;
- `src/style.css`, `src/template.html` — оформление и разметка;
- `tools/build.py` — генератор HTML и двух ZIP;
- `tests/` — проверочные скрипты Playwright/Chromium для разных графических режимов;
- `docs/` — документация и отчёт об ограничениях;
- `dist/` — **только локальная генерация или GitHub Release**, не в git.

## GitHub

При изменениях исходников, тестов, примеров или сборщика GitHub Actions запускает publish-release.yml. Коммит с пометкой `[matrix]` дополнительно запускает Chromium на Linux и Windows, Firefox на Linux и WebKit на macOS. После успешных проверок задача публикации создаёт отсутствующий тег vX.Y.0 по VERSION из tools/build.py, прикрепляет обе сборки HTML, Portable.zip, Source.zip и доступные отчёты. Контрольные суммы двух HTML и двух архивов включены начиная с 19.9 и в сводном выпуске 19.0. Существующий тег сохраняет исходные файлы.
