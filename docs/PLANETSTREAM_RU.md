# PlanetStream 17.1 — офлайн-пакет региона

Откройте HTML, затем «Атлас» → «Папка тайлов» и выберите каталог `examples/region` из portable ZIP. Карта переместится в учебную гавань и покажет синтетическое здание. Под картой выводятся авторство, лицензия и категория достоверности. Для переключения обратно на демонстрацию Керчи нажмите «Демо».

В корне папки находится `index.json`. Формат `TrussLabPlanetRegion` версии 1 оборачивает существующий `TrussLabRegionIndex` версии 1. В образце даны все обязательные поля. Границы записываются как запад, юг, восток, север в градусах WGS84, центр — долгота и широта. Область задаётся одним прямоугольником в пределах проекции Меркатора. Область, пересекающую антимеридиан, в этой версии делят на два пакета.

Ключ тайла — координаты ячейки EPSG:3857, округлённые вниз после деления на размер тайла. Файлы GeoJSON содержат координаты WGS84. Атрибуция и лицензия относятся ко всему пакету. Для источников разного происхождения создавайте отдельные пакеты. Допустимые значения достоверности — `confirmed`, `approximate`, `demo`, `missing`. Они передают оценку составителя. Старые каталоги с индексом и тайлами открываются прежним способом.

## 17.2 — подготовка собственных регионов

Для игры достаточно HTML и папки готового пакета. Для подготовки карт установите зависимости командой `python -m pip install -r tools/requirements-region.txt`. Пример запуска на компьютере автора карты:

```sh
python tools/import_region.py --parquet roads.parquet --cog imagery.tif \
  --output harbour --name "Гавань" --attribution "Автор карты" \
  --license-name "Лицензия исходных данных" --quality approximate
```

Можно передать только один источник. Импорт выполняется отдельным процессом. Векторные строки читаются партиями по 256, геометрия обрезается по границам тайлов, промежуточные записи хранятся на диске. Растр перепроецируется окнами по 256×256 пикселей. Исходные файлы сохраняются. Готовый каталог появляется после успешного завершения. Для повторного импорта используйте новое имя.

Поддерживаются линии и полигоны GeoParquet WKB с известной системой координат и восьмибитные серые либо RGB-изображения COG. Отсутствующие данные остаются прозрачными. Один пакет поддерживает до 200 000 ячеек 2048 м, 25 000 объектов и 4 МБ в одном векторном тайле. Лицензия и авторство должны подходить ко всем источникам пакета.

## 17.3 — обзор покрытия

При отдалении атлас переключается на иерархический индекс. Цветная ячейка показывает наличие данных, подпись — число занятых тайлов. На этом масштабе файлы геометрии и изображений не загружаются. При увеличении масштаба снова появляются исходные объекты.

## 17.4 — потоковый просмотр в 3D

В атласе нажмите «Пакет в 3D». Камера открывается в центре текущего вида. Перетаскивание перемещает камеру, колесо меняет масштаб. Мышь можно заменить стрелками и клавишами +/− при фокусе на холсте. Растр, дороги и объёмы зданий загружаются только вокруг камеры. За кадр создаются до двух мешей; бюджет их буферов и текстур — 24 МиБ. Счётчик отображает объём выделенных ресурсов приложения. Закрытие окна освобождает эти ресурсы.

## 17.5 — выбор региона

«Атлас» → «Глобальный атлас» показывает географическое положение и покрытие открытых пакетов. Выберите маркер на координатной сетке или регион в списке. Учебная гавань встроена в HTML. Последние восемь пакетов доступны для переключения в текущем сеансе, без повторного чтения исходных растров целиком.

## 17.6 — локальные метрические координаты

Каждый меш хранится в системе восток–север–вверх своего тайла. Для отображения в «Пакет в 3D» камера задаёт собственное начало WGS84. Положение и поворот между базисами вычисляются до отправки в GPU. Высоты объектов остаются в метрах при смене широты. При перемещении камеры загруженные меши используются повторно.

## 17.7 — права растрового и векторного слоёв

Пакет может указать отдельные записи `layers.vector` и `layers.raster` с полями `attribution`, `license`, `quality`. Передайте их объектом JSON через `--layer-credits rights.json`. В атласе доступна детализация по слоям, в 3D рядом со статистикой выводится атрибуция. Если права на слои одинаковы, достаточно общей записи пакета.

## 17.8 — частичные данные

Вектор и растр одного тайла читаются независимо. При отсутствии изображения остаются дороги и контуры. При отсутствии геометрии виден доступный растр. Атлас отдельно считает частично загруженные и полностью отсутствующие тайлы. «Повторить загрузку» повторяет запросы после сбоя. Если файлы добавлены в локальную папку, выберите её заново, чтобы браузер получил обновлённый список.
