# TrussLab Architect 13.0 — RenderCore Complete

Стабильный контрольный выпуск на базе предыдущей 13.0 и проверочной сборки RenderCore Completion.

## Загрузка

- **TrussLab_Architect_13_0.html** — автономная HTML-версия для браузера, в том числе на телефоне.
- **TrussLab_Architect_13_0_Portable.zip** — компактный архив: HTML + инструкция.
- **TrussLab_Architect_13_0_Source.zip** — исходный код, сборщик, тесты и документация.
- **Code → Download ZIP** на главной странице репозитория — те же актуальные исходники, без готовых сборок.

## Что работает

- Инженерные профили дороги и двухпутной ж/д, цифровые данные GeoPack, 2D/3D и FreeCam;
- исправленная ориентация нормалей асфальта и более корректные тени;
- WebGL2 и WebGL1-совместимость, GGX/ACES, каскадные тени;
- отражение статического моста, волны и береговые материалы без выдуманной батиметрии;
- mipmaps, BC3 при поддержке GPU, WebGL2 texture arrays; FXAA/TAA;
- ночное освещение, управляемые фары, оценка GPU-ресурсов и панель качества.

## Ограничения

Не заявлены картографическая точность 1:1, настоящая батиметрия, полная аппаратная проверка WebGPU, уровень UE5 или FPS на пользовательской RTX 4060 Ti. Функции проверены в браузере Chromium с программной WebGL-отрисовкой. Не все запланированные пункты исторических дорожных карт выполнены в полноте исходных целей.

## Сборка из GitHub

Установите Python 3.10+. Выполните `python tools/build.py`. Готовые HTML/ZIP появятся в `dist/` локально, но не добавляются в git. Состояние тестов: `docs/AUDIT_11_12_RU.md`.
