# TrussLab Architect 13.0 — Adaptive Frame Pipeline

## Состав версии

Главный исправленный дефект — перепутанные нормали асфальтового полотна: в 11.4 все 410 проверенных треугольников были направлены вниз. В обновлённой геометрии нормали покрытия направлены вверх; дополнительно исправлены грани бетонных блоков и части железнодорожного основания.

Пересмотрено фоновое солнечное освещение в WebGL1 (полусферический sky fill), уменьшена вероятность самозатенения, улучшен тональный баланс дневных материалов. При одинаковом тестовом ракурсе с включёнными тенями контрольная средняя яркость выросла примерно вдвое; это не точная оценка физической освещённости.

Добавлены:
- Естественный, архитектурный и кинематографический профили освещения без перестройки статической сцены;
- Частота транспорта: авто по FPS (6–18 Гц), плавная (18 Гц), экономная (6 Гц);
- Экранный пульт FreeCam для сенсорного управления;
- Политики рендера: Ультра (фиксированный), Авто FPS (с гистерезисом и 58–100% внутреннего масштаба), Эконом;
- Оверлей производительности и локальная закладка камеры.

## Самостоятельная сборка

В каталоге репозитория выполнить:

```bash
python src/offline13/build.py
```

Созданный HTML будет лежать в `dist/TrussLab_Architect_13_0.html`; **он не хранится в GitHub**. Сборка использует только стандартную библиотеку Python. Все примеры GIS и графических ресурсов уже содержатся в JavaScript-источнике.

## Ограничения

Встроенная география и мостовая инфраструктура не являются инженерно подтверждённой реконструкцией 1:1. Это WebGL1 и резервная программная отрисовка (с экспериментами WebGPU в региональном мире), не UE5. Проверка была в Chromium с программным WebGL; производительность на реальной RTX 4060 Ti, Android GPU и других устройствах не измерена. Оригинальные модульные исходники версии 12.0 остаются в `js/`, а автономный снимок 13.0 — в `src/offline13/`.
