# Разработка TrussLab Architect 11.0

## Проверка

Рабочая база: Node.js (ES modules), Python 3.11+, Chrome/Edge. Библиотеки GIS для запуска встроенного HTML **не нужны**.

- `npm test` — все модульные тесты.
- `python build.py` — собирает автономные HTML из `index_dev.html`, `style.css` и модулей `js/` в предписанном порядке.
- `python tests/browser_smoke_v11.py` — Playwright + Chromium (установить Playwright отдельно). Проверяет ENU-геометрию, размещение GLB, сохранение камеры, атлас и JS-ошибки.
- `start_windows.cmd` — необязательный запуск Electron с Node.js.

## Архитектура

- `js/world3d.js`: мост (наследуемая приблизительная локальная система), отдельные статическая и динамическая геометрии.
- `js/georef.js`: старый приблизительный адаптер координат игрового моста.
- `js/geodesy_enu.js`: геодезические преобразования WGS84/ECEF/ENU.
- `js/geo_metric.js`: метрическая региональная сцена, адаптер старого Меркатора и сохранений камер.
- `js/region3d*.js`: LOD-тайлы геометрии рельефа, 3D-камера, GPU и кэш.
- `js/region_tiles.js`: EPSG:3857-индекс внешних GeoJSON — хранится без изменения.
- `js/region_assets.js`: размещённые в WGS84 модели GLB.
- `js/webgpu_renderer.js`: экспериментальный GPU-рендерер; WebGL/2.5D fallback.
- `data/kerch_geopack.json`: геоданные поверхности и суши, атрибуция в метаданных.

### Тестирование изменений

Перед публикацией изменённого модуля проверьте `npm test`, сборку `python build.py` и работу переключателей 2D/3D. Не смешивайте высоты WGS84 над эллипсоидом с DSM Copernicus. Не путайте существующие OSM-контуры и процедурные иллюстрации.

### Важные ограничения

Детальная трасса моста, проектные параметры арок, точные отметки опор и расположение каждого здания **не подтверждены**. Не используйте результат для инженерных расчётов или заявлений об официальной реконструкции.
