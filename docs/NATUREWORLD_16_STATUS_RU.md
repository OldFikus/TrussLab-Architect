# NatureWorld 16.0–16.9 — текущий статус разработки

**Статус: промежуточная автономная HTML-сборка, ещё не GitHub Release.** Ветку `main` и файлы опубликованного `v15.0.0` заменять не требуется. Фактическая версия последнего готового выпуска на GitHub — **15.0 InfrastructureSim**.

В локальной контрольной сборке на основе CitySim 15.9 и WorldStream 15.10 экспериментально реализованы:

| План | Испытанная игровая функция |
|---|---|
| 16.1 | Почвы, породы и биомы как детерминированная *учебная* классификация, не реальные геологические данные |
| 16.2 | Деревья/трава с ограничением количества экземпляров и GPU-буферов |
| 16.3 | Движущиеся погодные фронты, осадки, облачность, ветер, туман |
| 16.4 | Анимированные блики воды и прибрежная полоса, не гидродинамика |
| 16.5 | Игровое солнце, плавная дневная яркость в WebGL и времена года |
| 16.6 | Отдельные редактируемые слои озёр и речных русел; исходный DEM не меняется |
| 16.7 | Сезонные оттенки процедурной растительности |
| 16.8 | Условные коэффициенты влияния погоды на визуальный транспорт и видимость |
| 16.9 | Эко/сбалансированный/высокий бюджеты экосистемы и стресс-тесты |

Тесты: 110 позиций камеры и 75 водоёмов; WebGL на десктопной и мобильной ширине, сохранение старого CitySim GZIP. Все результаты относятся к **вымышленному игровому миру 12×12 км**. Kerch GeoPack и его Copernicus DEM не подменяются. Это не моделирование реальной погоды, батиметрии, грунтов или конструкции Крымского моста 1:1.

Исходные задачи 16.1–16.9 сохранены полностью в [дорожной карте](../ROADMAP_10_8_TO_20_0_RU.md). Соответствие старых 13–15 выпусков — в [каталоге](RELEASE_CATALOG_RU.md). Серия 16 не считается **опубликованным выпуском**, пока её проверенная самостоятельная сборка не появится отдельным крупным GitHub Release.
