## Используемые формулы (для проверки численного ядра)

В учебной модели сосредоточенная вертикальная сила P = m·g (g = 9,81 м/с²), пролёт L опирается на две шарнирные опоры. Для нагрузки P в середине пролёта реакции опор Rₐ = Rᵦ = P/2, максимальный момент Mₘₐₓ = P·L/4, максимальный прогиб δ = P·L³/(48·E·I). Для равномерно распределённой нагрузки q: Rₐ = Rᵦ = q·L/2, Mₘₐₓ = q·L²/8, δₘₐₓ = 5·q·L⁴/(384·E·I). Суммарные усилия и прогибы рассчитываются по принципу суперпозиции.

Для основания: q = N/A, коэффициент загрузки = q/R_доп, осадка по упрощённой упругой полуплоскости s ≈ (q/E)·B·(1−ν²). Эти формулы здесь не включают сложную геологию, ползучесть, сейсмику и реальные нагрузки, поэтому рассчитанные значения **не пригодны для строительного проектирования**.

## Масштаб, производительность и ограничения

- Граф хранит расстояния в ENU-метрах, но исходное положение реального моста не подтверждено исполнительной геодезией.
- Для локального браузера ограничены дороги (до 2000 сегментов и 7500 вершин), автомобили (до 250), поезда (20), суда (15). Пределы введены для управляемой нагрузки в HTML.
- Изменение линий через WorldEditor перестраивает только граф InfrastructureSim; исходный GeoPack остаётся без изменений.
- В браузере есть 2D-карта движущихся агентов. Старый декоративный 3D-трафик игрового мостового режима пока отдельный и не объявляется той же физической симуляцией.
- Тестирование выполнено через Node.js и Chromium с программным графическим адаптером; FPS на телефоне и RTX 4060 Ti требует проверки владельцем.
- 14.0 опубликован в GitHub Release как WorldEditor 2. Эта версия 14.9 — **локальный проверочный этап**. В GitHub она не публиковалась до следующего согласованного крупного обновления.
