# TrussLab Architect 9.4.2 — продление подходов до суши по GeoPack

## Зачем нужно исправление

GeoPack показывает настоящую береговую маску и данные DEM. Геометрическая ось из 9.4 задана условно и заканчивается на координатах X=-118 и X=+118, то есть её конец может быть ещё в воде. В 9.4.1 уже можно было передвигать концевые точки поперёк (Z), но нельзя было увеличивать длину подходов (X). Теперь это можно сделать без изменения DEM или OSM.

## Как воспользоваться

1. Откройте автономный HTML 9.4.2 либо запустите локальную версию Windows.
2. Выберите **Крымский мост**, затем **3D**.
3. Через кнопку **📦 OSM + DEM** укажите ваш ранее созданный `E:\TrussLab_Architect_9_3\data\kerch_geopack.json`. Повторное скачивание не нужно.
4. Нажмите **⇤⇥ Подходы к берегам**. Будет построен **предпросмотр** на 2D-плане: две жёлтые пунктирные линии от исходных концов до обнаруженной устойчивой суши.
5. Если результат подходит, нажмите **✓ Применить подходы** в верхней панели 2D. Если нет — **× Отмена подгонки**. Применение можно отменить кнопкой «Отмена»/Ctrl+Z.
6. Нажмите **◎ Берег × трасса** для повторной диагностики. Проверьте оба конца автомобильной дороги и железной дороги. Затем перейдите в 3D.
7. Нажмите «Проект» → «Скачать JSON», чтобы сохранить изменение длины подходов вместе с вашим GeoPack.

### Как работает поиск

Алгоритм проверяет береговую маску в направлении существующих условных осей, от каждого конца наружу. Требуется, чтобы **и автомобильная линия, и железнодорожная** не менее 320 м подряд проходили по суше (значение маски > 70%). Поиск ограничен ближайшими 4,8 км и границами карты. Ни один слой GeoPack не редактируется.

Если на одном из берегов суша не найдена, параметры трассы **не изменятся**. Это означает, что направление оси нужно уточнять реальным GeoJSON или настоящей координатной калибровкой, а не вручную передвигать берег.

### Ограничения

- Это **игровая, визуальная подгонка длины подходов**, а не определение фактической оси Крымского моста и не реконструкция 1:1.
- Географическая привязка игры ещё приблизительная (одна опорная точка).
- Исторический OSM-архив может упрощать остров Тузла и косы; Copernicus GLO-30 — DSM, а не съёмка несущих конструкций.
- Для точной калибровки загрузите в разговор сам `kerch_geopack.json` (не только скриншот) и, по возможности, GeoJSON осей дороги и железной дороги.

Тесты: `npm test`. Проверка браузера выполнялась на синтетическом GeoPack, не на пользовательском файле.
