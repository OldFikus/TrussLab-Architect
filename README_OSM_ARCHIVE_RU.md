# TrussLab GIS: OSM без Overpass и EMODnet

Этот загрузчик использует **заранее обработанный OSM-производный архив морских полигонов** `@geo-maps/earth-seas-10m` версии 0.6.0, опубликованный в npm. В отличие от Overpass/WFS, он скачивает готовый файл и вычисляет маску воды/суши локально.

**Это исторический набор, созданный приблизительно в 2017 году, а не актуальная онлайн-карта OSM или точная геодезическая съёмка.** Данные основаны на OSM `natural=coastline`, распространение — ODbL; © OpenStreetMap contributors. Номинальная детализация источника ~10 м не означает точность геопривязки самого моста в TrussLab.

## Установка

1. Уже имеющийся `data\kerch_geopack.json` с Copernicus DEM **не перемещайте и не удаляйте**.
2. Распакуйте этот ZIP в `E:\TrussLab_Architect_9_4\` так, чтобы новый файл оказался по пути `E:\TrussLab_Architect_9_4\tools\prepare_osm_archive.py`. Файл `tools\prepare_geodata.py` перезаписывать не нужно.
3. Запустите `prepare_osm_archive_windows.cmd`. Скрипт попробует скачать один архив из npm (интернет нужен только один раз). После первой успешной загрузки архив сохраняется в `data\source_downloads`.
4. Если написано `УСПЕШНО`, просмотрите `data\kerch_geopack.preview.png`. Убедитесь, что Керчь, Тузла и Тамань отображаются без перевёрнутых суши/воды.
5. Снова импортируйте `data\kerch_geopack.json` в TrussLab через `📦 OSM + DEM`.

## Если registry.npmjs.org тоже недоступен

Архив можно скачать в браузере по адресу:
https://registry.npmjs.org/@geo-maps/earth-seas-10m/-/earth-seas-10m-0.6.0.tgz

Положите скачанный `.tgz` в папку `data\source_downloads`, затем повторно запустите CMD. Либо явно передайте путь:

```powershell
cd 'E:\TrussLab_Architect_9_4'
py -3 .\tools\prepare_osm_archive.py --archive 'E:\Downloads\earth-seas-10m-0.6.0.tgz' --output '.\data\kerch_geopack.json'
```

Если и npm недоступен, исходная DEM-карта не изменится; можно продолжать использовать исходную береговую линию 9.3.

### Границы точности и лицензия

- Источник: OSM-производные полигоны мировых морей (`earth-seas-10m` v0.6.0), **не обновлённые данные**. © OpenStreetMap contributors, ODbL 1.0. Производная геометрия — с того же исторического среза.
- Этот вариант использует растеризацию **полигонов воды**, а не определение суши по ближайшей незамкнутой линии, что уменьшает ошибки возле кос и островов.
- При ошибке или подозрительном результате геопакет не заменяется; тестовая PNG-карта позволяет проверить берег до импорта.
- Рельеф Copernicus GLO-30 сохраняется без изменений.
