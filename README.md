# TrussLab Architect

**Версия 13.0 · RenderCore Complete** — браузерный конструктор мостов и экспериментальный географический 3D-мир. Основной демонстрационный район — Керченский пролив (Керчь, Тузла, Тамань).

> **Важно:** мост, элементы берегов и часть зданий — приближённые игровые модели, а не точная реконструкция реального перехода 1:1. Движок основан на JavaScript и WebGL1/2 с экспериментальными компонентами WebGPU; это не Unreal Engine 5.

## Скачать и запустить

**[Скачать последнюю сборку из Releases](https://github.com/OldFikus/TrussLab-Architect/releases)** — автономный HTML, portable ZIP и исходный архив.

Если нужны **только исходники** — нажмите зелёную кнопку **Code → Download ZIP** на этой странице. Репозиторий намеренно не содержит готовые HTML, EXE или архивы.

Для локальной сборки установите Python 3.10+, затем выполните:

```bash
python tools/build.py
```

Готовый HTML появится в `dist/TrussLab_Architect_13_0.html`. Он открывается в браузере без сервера и без скачивания дополнительных игровых материалов.

## Основные возможности

- Мост с автомобильной и двухпутной железнодорожной частью, условными пролётами, трафиком и редакторами;
- OpenStreetMap-производные береговые линии и высоты Copernicus GLO-30, 2D/3D и FreeCam;
- исправленные материалы, ночной свет, волны, отражения, тени, режимы графики;
- WebGL2 + совместимый WebGL1; производительность зависит от устройства.
