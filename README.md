# TrussLab Architect

Экспериментальный **браузерный 2D/3D-конструктор мостов и географический симулятор**. Основная тестовая территория: Керченский пролив, Керчь, остров Тузла и Таманский полуостров.

**Текущий релиз: 11.0 GeoCore 2.** В нём региональный 3D использует локальные метрические координаты ENU. Сохраняются мостовой редактор, двухпутная железная дорога, моделирование трафика, GeoCity, TerraBuild, AssetStudio, WebGL и экспериментальный WebGPU.

> Внимание: это игровая географическая модель, **не точная реконструкция 1:1**, не Unreal Engine 5 и не профессиональная программа для расчёта безопасности сооружений.

## Начать работу

1. Для автономного HTML запустите `python build.py`. Он создаст `TrussLab_Architect_11_0_Standalone.html` и `index.html`.
2. Откройте HTML в Chrome или Edge. DEM, демонстрационная застройка и оригинальные 3D-модели уже встроены; загрузка из интернета не требуется.
3. Для запуска из исходников во время разработки используйте локальный сервер, например `python -m http.server 8000`, и откройте `index_dev.html`.
4. Проверки: `npm test`. Настольная оболочка Electron: `npm install`, `npm run desktop` (не требуется для HTML).

## Исходники

- `js/` — игровые модули, физика, карта и GPU-движок; `js/geodesy_enu.js` и `js/geo_metric.js` — 11.0.
- `data/` — GeoPack и демонстрационные региональные тайлы.
- `assets/models/` — шесть оригинальных GLB 2.0.
- `tests/` — автоматические тесты от 9.x до 11.0.
- `tools/` — утилиты подготовки GIS и экспорта.
- `desktop/` — Electron.
- `index_dev.html`, `style.css`, `build.py`, `package.json` — исходная страница, стили, упаковщик и задачи.

## Точность и права на данные

GeoPack создан на основе Copernicus GLO-30 DSM и исторического OSM-производного набора берегов (© OpenStreetMap contributors, ODbL 1.0). Отметки DEM не являются инженерными измерениями. GeoJSON городов Overture/OSM может потребовать дополнительных атрибуций при импорте.

Исходный спутниковый скриншот пользователя **не включён в публичный репозиторий**, чтобы не распространять материалы картографических сервисов без разрешения. Для локального сравнения его можно добавить в `assets/satellite_reference.jpg` при наличии прав использования. Сборка работает и без него.

Статус: исследовательский проект. Графика и производительность на конкретной GPU пользователя проверяются отдельно.
