# TrussLab Architect 14.0 — WorldEditor 2

**Автономный 2D/3D-редактор с геопривязкой WGS84 и региональной сценой Kerch–Tuzla–Taman.** Переход от предыдущей 13.0 к 14.0 отражает объединение инструментов WorldEditor 2; InfrastructureSim 14.1–14.9 — следующий проектный этап.

- [Релиз v14.0.0: автономный HTML и ZIP](https://github.com/OldFikus/TrussLab-Architect/releases/tag/v14.0.0)
- [Документация редактора](docs/RELEASE_14_RU.md)
- [Дорожная карта до 20.0](ROADMAP_10_8_TO_20_0_RU.md)

## Возможности

Создание и редактирование участков и зон, домов, улиц, двухпутных линий, условных стрелок, инженерных сетей, правок рельефа поверх неизменного Copernicus DSM. Каталог объектов с авторством, наследование материалов, история правок и снимки, экспорт/импорт JSON, загрузка географических осей, GIS-размещение с ручным подтверждением. Геоданные встроены для запуска без интернет-доступа.

## Сборка из исходников

```bash
python tools/build.py
node tests/test_worldeditor_core.cjs
node tests/test_wgs84_alignment.cjs
```

Требуются только Python 3 и Node.js (для тестов). Результат в `dist/` не хранится в Git; HTML и ZIP публикуются исключительно в **GitHub Releases**. Приложение запускается локальным файлом HTML. Для графических браузерных тестов дополнительно нужны Playwright и Chromium.

> Реальная геометрия Крымского моста и береговой инфраструктуры не подтверждена в масштабе 1:1. Доступны метрическая карта и инструменты редактирования, а не исполнительный цифровой двойник сооружения. Физические и транспортные функции 14.1–14.9 пока отсутствуют в релизе 14.0.
