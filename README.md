# TrussLab Architect

**TrussLab Architect** — экспериментальный браузерный симулятор мостов, географический 2D/3D-мир и редактор построек. Основной демонстрационный район — Керченский пролив (Керчь — Тузла — Тамань).

> Текущая ветка: **11.0 GeoCore 2**. Геометрия мостового перехода и отдельные объекты пока приближённые. Проект **не** является геодезически точной реконструкцией 1:1, Unreal Engine 5 или инженерным расчётным инструментом.

## Игровые возможности

- Редактирование мостовой трассы, арок, фундаментов, двух железнодорожных путей;
- автономная HTML-сборка, WebGL и экспериментальный WebGPU для регионального 3D;
- OSM-производные контуры суши и встроенный Copernicus GLO-30 GeoPack;
- TerraBuild: строительство на суше; GeoCity: импорт контуров зданий и дорог;
- RegionStream: региональные тайлы, кэширование, LOD, плавающее начало координат;
- AssetStream: GLB 2.0, отдельные демонстрационные модели и сохранение расстановки;
- GeoCore 2: переход регионального 3D с проекционных метров на локальные ENU-метры.

## Как запустить

**Самый простой путь:** открой готовый файл `dist/TrussLab_Architect_11_0.html` в поддерживаемом браузере, когда сборка опубликована в репозитории или приложена в чате. Все демонстрационные ресурсы находятся внутри HTML.

**Из исходников:** см. [документацию разработки](docs/DEVELOPMENT_RU.md); для тестов требуется Node.js. Electron — необязательный настольный контейнер.

## География, достоверность и лицензии

- OSM-производные береговые данные: © OpenStreetMap contributors, ODbL 1.0; снапшот берегов может быть историческим.
- Copernicus DEM GLO-30: модель поверхности DSM (не съёмка морского дна и не геодезический проект).
- Overture Maps: внешний источник географических контуров; демонстрационные здания TrussLab — синтетические.
- Точные параметры конструкций, инженерная безопасность и масштаб 1:1 **не подтверждены**.
- Использовать Google Maps / Street View как массовый источник скачиваемых текстур нельзя без необходимых разрешений.

## Структура репозитория

| Путь | Содержимое |
|---|---|
| `src/` | Исходный код текущей версии (по мере синхронизации) |
| `dist/` | Автономные HTML-сборки |
| `data/` | Демонстрационные данные и описание происхождения |
| `docs/` | Архитектура, инструкции, источники и ограничения |
| `archive/` | Найденные исторические прототипы и версии, без выдуманной истории Git |

## Планы

[План версий 11–20](docs/ROADMAP_RU.md): метрическая география → качество графики и ассеты → редакторы и физика → городская симуляция → крупные регионы → стабильный выпуск.

**Проверки:** модульные тесты дополняются браузерной проверкой. Аппаратные измерения FPS на ПК пользователя не проводятся в среде разработки.

Разработка ведётся при участии владельца проекта и ChatGPT. Указания авторства и лицензий внешних данных сохраняются отдельно от кода игры.
