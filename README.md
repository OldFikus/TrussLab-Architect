# TrussLab Architect — 13.0 Adaptive Frame Pipeline

**Новый автономный движок 13.0:** `src/offline13/` содержит полный JavaScript-код (включая встроенные демонстрационные данные), стили, HTML-шаблон и воспроизводимый сборщик. Для сборки: `python src/offline13/build.py`; результат — локальный `dist/TrussLab_Architect_13_0.html`. HTML, ZIP и EXE в репозиторий не загружаются.

**Исправление чёрных материалов:** перепутанная ориентация нормалей дорожных и бетонных граней, минимальная hemispheric sky-подсветка, уменьшенное самозатенение. Дополнительно — три цветовых профиля, адаптивный трафик, FreeCam для телефона, режимы GPU «Ультра / Авто / Эконом», индикатор FPS и закладки камеры.

**Важно:** автономный движок 13.0 является проверяемым цельным снимком исходников; ранее опубликованные модульные исходники 12.0 в `js/` сохранены отдельно, их объединение — следующая задача рефакторинга. Исходные геоданные и условная геометрия не являются мостом 1:1 или UE5. Проверка выполнена в Chromium/WebGL (программный драйвер), производительность на RTX 4060 Ti не измерена.

## TrussLab Architect — 12.0 RenderCore 2

Браузерный симулятор мостов и редактор географического мира: Керченский пролив, GeoCity / RegionStream / GeoCore, TerraBuild, GLB и экспериментальный WebGPU.

**Исходники версии 12.0.** Обновление включает промежуточную ветку 11.5–11.9: устои и стыки, разрезы рельефа, диагностику подходов, камеры и монитор производительности, настройки атмосферы. WebGL1 получил приближённые прямые отражения GGX и возможность возврата к прежнему освещению.

## Сборка

- `npm test` — регрессионные и новые модульные тесты на Node.js.
- `python build.py` — автономный HTML с встроенными демонстрационными ресурсами.
- `npm run desktop` — необязательный Electron.
- Документация: [README_RU.md](README_RU.md), [VERSION_12_0.md](VERSION_12_0.md), [QA_RELEASE_12_0_RU.md](QA_RELEASE_12_0_RU.md).

В `main` публикуются **исходники крупных версий**, не коллекция ZIP/HTML/EXE промежуточных сборок.

## Точность и ограничения

Трассировка и конструктивные детали моста пока игровые, не подтверждены геодезической съёмкой и не являются реконструкцией 1:1. Copernicus GLO-30 — цифровая модель поверхности, не батиметрия. География OSM-производна: © OpenStreetMap contributors, ODbL. Встроенные модели созданы для демонстрации. GGX — direct-light BRDF без сканированных PBR-текстур и IBL, это не Unreal Engine 5.
