# TrussLab Architect 10.2 — GeoCity: открытые здания и дороги

## Что действительно реализовано

GeoCity загружает **контуры** существующих зданий и наземных дорог из GeoJSON в формате WGS84/EPSG:4326, а не генерирует по умолчанию вымышленные дома. Каждый импортированный строительный полигон становится отдельной 3D-моделью в форме реального контура крыши (простая экструзия); дороги и железные дороги визуализируются на рельефе. Здания и дороги не заменяют редактируемый мост и не изменяют его трассу или физику. Импортированный слой рисуется отдельно от TerraBuild и транспорта, в GPU-буферах секторов 35×35 игровых единиц; при удалении слоя GPU-буферы освобождаются.

**Важно:** сцена 10.x охватывает ~33,6 × 33,6 км, пока НЕ весь Крым. Горизонтальная игровая единица ≈80 м, вертикальная ≈8 м, а координатная система опирается на *один* ориентировочный WGS84-репер. Внешние контуры остаются ориентировочными относительно игрового рельефа до геодезической калибровки. Копией 1:1 проект пока не является. Copernicus GLO-30 — DSM, не точная инженерная высота основания каждого здания.

## Быстрый импорт вручную

1. Откройте `index.html` или `TrussLab_Architect_10_2_Standalone.html` в Chrome/Edge. Для Windows можно запустить `start_windows.cmd` (требуется Node.js и Electron, при первом запуске интернет).
2. Выберите сценарий **«Крымский мост»**, режим **3D** или **2D → План местности**.
3. В панели **GEO CITY** нажмите **«↑ Здания + дороги»** и выберите файл `.geojson` с `FeatureCollection` в координатах `[longitude, latitude]` (EPSG:4326).
4. Постройка: `Polygon` или `MultiPolygon` с атрибутом `building`/`type=building`; дорога: `LineString` или `MultiLineString` с `highway`, `railway` либо Overture `subtype=road/rail` и `type=segment`.
5. Повторный выбор файла **добавляет** его к текущему GIS-слою. `◉ GIS: ВКЛ` скрывает/показывает только этот слой, `× Убрать GIS` удаляет его. Ручные постройки TerraBuild и GeoPack не меняются.
6. `↓ Проект` сохраняет исходные координаты GIS-слоя в проект. Для очень больших пакетов локальное хранилище браузера может быть слишком мало — используйте экспорт JSON проекта и храните исходные GeoJSON рядом с ним.

### Получение реальных открытых зданий Overture (Windows)

Запустите `prepare_geocity_windows.cmd` в распакованной папке. При первом запуске Python попробует установить CLI `overturemaps`. После этого последовательно загрузит здания и сегменты транспортной сети в **небольшой стартовой области Керчи**. Готовые файлы появятся в `data\geocity_import\geocity_kerch_01.geojson` и последующих частях.

Альтернативные команды в PowerShell из папки игры:

```powershell
py -3 -m pip install overturemaps
py -3 .\tools\download_geocity.py --area kerch --output .\data\geocity_import
py -3 .\tools\download_geocity.py --area tuzla --output .\data\geocity_import
py -3 .\tools\download_geocity.py --area taman --output .\data\geocity_import
```

`--area all` запрашивает все три стартовых района. Чтобы уменьшить объём, используйте `--buildings-only`. **Загрузчик выполняется на вашем компьютере при наличии интернета, в этой среде реальную связь с Overture протестировать не удалось.** На Python 3.14 отдельные пакеты CLI/GeoParquet могут потребовать совместимой версии Python 3.12–3.13. Если CLI не установится, используйте ручную загрузку открытого GeoJSON через [Overture Explorer](https://explore.overturemaps.org/) или скачивание из QGIS с корректной атрибуцией.

Программа разбивает скачанный набор на небольшие GeoJSON-файлы и не изменяет ваш `kerch_geopack.json`. **Не скачивайте всю планету** одной командой: нужны порционные наборы для конкретного участка, далее потребуется полноценное GIS-тайловое хранилище вне JSON-проекта.

## Что точно/неточно

- **Геометрия:** исходные вершины контуров из GeoJSON, после *приближённого* перевода WGS84 в локальную систему — не полная геодезия.
- **Высота:** если есть `height` или `building:height` в метрах, используется она. Иначе, если указано `building:levels`, берётся ~3,2 м на этаж. Если данных нет — условные 9,5 м. Геометрия и высоты не подтверждены съёмкой.
- **Детализация:** дома — облегчённые экструдированные модели; ни окна/фасады реальных адресов, ни фотограмметрия, ни 3D-панорамы не включены.
- **Полигоны с внутренними кольцами (дворами/отверстиями)** пока пропускаются целиком, чтобы не заливать отсутствующие части крыши. Вогнутые простые полигоны обрабатываются триангуляцией. Ограничение: до 128 вершин одного кольца.
- **Система:** максимум 16 000 GeoJSON features или 280 000 координат суммарно за одну загруженную область, ограничение файла интерфейса — 25 МБ. Сильно длинные дороги разбиваются на сегменты; нужно дополнительное разбиение на файлы для большой территории.
- **Браузер:** WebGL1; не UE5, нет Nanite/Lumen/WebGPU pipeline и реального городского трафика на импортированных дорогах. Импортированные дороги — только визуальные линии; игровой трафик продолжает использовать мостовые маршруты.

## Права на данные, почему не скриншоты Google

- **Overture Maps Foundation:** темы Buildings/Transportation могут содержать OSM и распространяться на условиях ODbL. При использовании/распространении производных данных сохраняйте атрибуцию © OpenStreetMap contributors, Overture Maps Foundation и проверяйте лицензии поставщиков (`https://docs.overturemaps.org/attribution/`).
- **Google Maps/Street View:** не используйте массовое скачивание панорам или тайлов Google для самостоятельной 3D-базы. Условия Google Maps Platform ограничивают скрейпинг, кэширование и перепубликацию; для прямого встраивания сервиса нужны разрешённые API и соблюдение условий. Панорамы могут использоваться пользователем как визуальные ориентиры в рамках разрешённого просмотра, но не как автоматически извлечённые игровые ресурсы.
- **Mapillary:** фотографии могут помочь при проверке фасадов, но нужно отдельно соблюдать ограничения API и атрибуцию/лицензии каждого изображения.

## Дальнейшие этапы

**10.3+**: мультикалибровка WGS84 (несколько контрольных пунктов), глобальные тайлы DEM/береговой линии в метрах, плавающий origin и 64-битные координаты, пространственный индекс/GERS IDs, генерация тротуаров и локальных улиц по GIS, LOD instancing, текстурные атласы, PBR-материалы, WebGPU, потоковый импорт с диска без упаковывания всей страны в один JSON. Точные 3D-модели отдельных важных зданий должны изготавливаться/лицензироваться отдельно. **Перенос всего Крыма 1:1 не сделан в 10.2.**
