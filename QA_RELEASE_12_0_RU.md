# TrussLab Architect 12.0 — QA отчёт

- `npm test`: все регрессионные тесты 9.0–12.0 пройдены, включая подходы, поперечный разрез, инспектор 11.7, камеры 11.8, насыщенность/дымку 11.9, материалы 12.0.
- Chromium, ширина окна 412px: импортированная карта и поперечный разрез, инспектор подходов, WebGL/CPU-переключатель, камеры устоев, настройка GGX, дымка, статистика, региональный 3D. Ошибок JavaScript нет. WebGL в тестовом Chromium недоступен.
- Mesa OpenGL ES 2: программы основного шейдера, тени и небо компилируются и связываются.
- Real GPU (RTX 4060 Ti): НЕ тестировалось; FPS не обещаем.
- GeoDEM: исходные данные неизменны; инженерные габариты игровые, не 1:1.
- PBR: только direct-light GGX и процедурная шероховатость; нет полного metal/roughness текстурного pipeline и reflection probes.
