# TrussLab Studio — реализованные формулы и границы применимости

## 1. Плоская механика мостов

Модель 2D: каждому узлу соответствуют `ux`, `uy`, `θz` (3 степени свободы). Простые стержни и тросы передают только продольное усилие, рамные балки передают также поперечную силу и изгибающий момент. Матричное уравнение равновесия: **K u = F**. Закреплённые степени свободы исключаются; подматрица решается методом Гаусса с выбором ведущего элемента.

**Осевые стержни:** `L = sqrt(Δx² + Δy²)`, `k_a = EA/L`, `N = EA/L * [(u_j − u_i) · n]`, где `n=(Δx/L, Δy/L)`; `E` — модуль Юнга, `A` — площадь сечения.

**Рамная балка Эйлера–Бернулли:** в локальной системе используется классическая матрица изгибной жёсткости для DOF `[v_i,θ_i,v_j,θ_j]` с коэффициентами `12EI/L³`, `6EI/L²`, `4EI/L`, `2EI/L`; матрица поворачивается в глобальную систему. Поворот сечения учитывается; сдвиг по Тимошенко и пластичность — нет.

**Эйлерова потеря устойчивости:** `N_cr = π² E I / L²` — приближённый предел для идеализированных условий закрепления. В игре `N_allow = min(f_c A, N_cr)` при сжатии, `N_allow = f_t A` при растяжении. Для рамных элементов добавлена приблизительная формула `η = |N|/N_allow + |M|/(f_t W)`, где `W≈sqrt(AI/12)` — прямоугольное эквивалентное сечение. Значение `η≤1` условно считается проходным. Это не соответствует полноценной проверке строительных норм.

**Прогиб:** `δ_max = max_i sqrt(ux_i² + uy_i²)`; для каждой игровой миссии задан порог в метрах. Для экрана деформации **специально преувеличены**.

**Тросы:** первая версия использует линейную осевую жёсткость `EA/L`; отрицательное усилие помечается как нарушение. Итеративное натяжение, предварительное напряжение, геометрическая нелинейность и реальная цепная линия **не рассчитываются**. Поэтому схемы Золотых Ворот и подобных мостов стилизованные и не годятся для технических расчётов.

**Нагрузочные случаи:** «транспорт» использует заданные узловые вертикальные силы; «снег» умножает их на условный коэффициент 1.45; «ветер» добавляет условную горизонтальную составляющую; «сейсмика» добавляет условную горизонтальную составляющую. **Это игровые сценарии, не расчётные сочетания по нормам.** Собственный вес элементов не добавляется в нагрузки автоматически.

## 2. Грунты и фундаменты

Все геотехнические параметры являются игровыми пресетами, не лабораторными измерениями и не нормами.

Для мелких подошв используется **приближённая формула Терцаги** с фактором формы и с упрощённым `Nγ`:

- `Nq = exp(π tanφ) tan²(45°+φ/2)`
- `Nc = (Nq − 1)/tanφ`, при `φ=0` заменяется на 5.7
- `Nγ ≈ 2(Nq+1) tanφ` (приближение по Везичу)
- `q_ult ≈ c Nc + γ D Nq + 0.5 γ B Nγ`
- `q_allow = q_ult/3`, `q=P/A`
- `s ≈ q B (1-ν²)/E_s × 1.05` — упругая оценка осадки

Коэффициент формы применён к выражению приближённо. Поправки на эксцентриситет, уклон, неравномерные слои и множество иных факторов отсутствуют. Высокие грунтовые воды в игре уменьшают удельный вес и увеличивают условную осадку.

Для свай: `Q_ult ≈ A_tip q_tip + π d L f_s`, `Q_allow ≈ Q_ult/3`; для свайного поля `Q_allow,total = n Q_allow` с приближённой верхней границей прочности самих свай. `q_tip` и `f_s` — **игровые зависимости**, рост сопротивления по глубине условно изображает более плотный подстилающий слой, но слои в модели НЕ задаются. Осадка свайного поля оценивается через условную жёсткость пружины и сжатие сваи. Для реального основания применять нельзя.

## 3. В чём ограничен «3D»-режим

Поворотная **трёхмерная геометрическая визуализация** строится на объёмной экструзии плоской модели и перспективно-изометрической проекции Canvas2D. Геометрия изменяет координаты на трёх осях и допускает вращение, но решатель остаётся **плоским**. Это не полноценный 3D МКЭ и не расчёт на кручение, боковой ветер или пространственное выпучивание.
